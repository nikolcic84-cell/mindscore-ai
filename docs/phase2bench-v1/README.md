# Phase 2 benchmark v1 historical artifacts

`capture_kind: extracted_cached_result_object`

`A.json` through `F.json` are the six fixture objects extracted from the available cached benchmark capture. Each file preserves the fields of its corresponding parsed object; the JSON has been pretty-printed for readability.

These are **not** original full HTTP captures. They do not claim to contain request/response headers, transport metadata, or any content absent from the captured objects. The source was a terminal-output capture, not a complete HTTP archive.
